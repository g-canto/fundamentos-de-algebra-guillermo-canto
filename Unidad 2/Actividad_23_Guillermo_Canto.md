# SERIE DE EJERCICIOS - 81 al 128

Para cada ejercicio de graficacion:

1. Se despeja la variable $y$.
2. Se evalúa en $x = -1$, $x = 0$ y $x = 1$.

---

### **Ejercicio 81**

$$x - y = 0$$

- **Despeje de $y$:**
  $$y = x$$

- **Tabulación de puntos:**
  - Para $x = -1$: $y = -1 \implies A(-1, -1)$
  - Para $x = 0$: $y = 0 \implies B(0, 0)$
  - Para $x = 1$: $y = 1 \implies C(1, 1)$

---

### **Ejercicio 82**

$$x + 4y = -8$$

- **Despeje de $y$:**
  $$4y = -x - 8 \implies y = -\frac{x + 8}{4} = -\frac{1}{4}x - 2$$

- **Tabulación de puntos:**
  - Para $x = -1$: $y = -\frac{-1 + 8}{4} = -\frac{7}{4} = -1.75 \implies A(-1, -1.75)$
  - Para $x = 0$: $y = -\frac{0 + 8}{4} = -2 \implies B(0, -2)$
  - Para $x = 1$: $y = -\frac{1 + 8}{4} = -\frac{9}{4} = -2.25 \implies C(1, -2.25)$

---

### **Ejercicio 83**

$$7x + y = 2$$

- **Despeje de $y$:**
  $$y = 2 - 7x$$

- **Tabulación de puntos:**
  - Para $x = -1$: $y = 2 - 7(-1) = 2 + 7 = 9 \implies A(-1, 9)$ _(fuera de la cuadrícula superior)_
  - Para $x = 0$: $y = 2 - 7(0) = 2 \implies B(0, 2)$
  - Para $x = 1$: $y = 2 - 7(1) = 2 - 7 = -5 \implies C(1, -5)$

---

### **Ejercicio 84**

  - Para $x = 0$: $y = 2(0) + 1 = 1 \implies B(0, 1)$
  - Para $x = 1$: $y = 2(1) + 1 = 2 + 1 = 3 \implies C(1, 3)$

### **Ejercicio 97**

$$\frac{493}{32} - \frac{13}{8}x = -\frac{7}{4}\left(-\frac{11}{6}x + \frac{29}{8}\right)$$

1. Distribuir $-\frac{7}{4}$ en el lado derecho:
   $$\left(-\frac{7}{4}\right)\left(-\frac{11}{6}x\right) = \frac{77}{24}x$$
   $$\left(-\frac{7}{4}\right)\left(\frac{29}{8}\right) = -\frac{203}{32}$$
   La ecuación queda:
   $$\frac{493}{32} - \frac{13}{8}x = \frac{77}{24}x - \frac{203}{32}$$

2. El mcm de los denominadores $\{32, 8, 24\}$ es $96$:
   Multiplicamos toda la ecuación por $96$:
   $$96 \cdot \frac{493}{32} - 96 \cdot \frac{13}{8}x = 96 \cdot \frac{77}{24}x - 96 \cdot \frac{203}{32}$$
   $$3(493) - 12(13)x = 4(77)x - 3(203)$$
   $$1479 - 156x = 308x - 609$$

3. Despejar $x$:
   $$1479 + 609 = 308x + 156x$$
   $$2088 = 464x$$
   $$x = \frac{2088}{464} = \frac{9}{2}$$

$$\mathbf{x = \frac{9}{2}}$$

### **Ejercicio 98**

$$\frac{5}{3} + x = -\frac{7}{6}\left(x - \frac{9}{5}\right)$$

1. Distribuir $-\frac{7}{6}$:
   $$\frac{5}{3} + x = -\frac{7}{6}x + \frac{63}{30} = -\frac{7}{6}x + \frac{21}{10}$$

2. Multiplicar toda la ecuación por el mcm$(3, 6, 10) = 30$:
   $$30\left(\frac{5}{3}\right) + 30(x) = 30\left(-\frac{7}{6}x\right) + 30\left(\frac{21}{10}\right)$$
   $$50 + 30x = -35x + 63$$

3. Despejar $x$:
   $$30x + 35x = 63 - 50$$
   $$65x = 13$$
   $$x = \frac{13}{65} = \frac{1}{5}$$

$$\mathbf{x = \frac{1}{5}}$$

### **Ejercicio 103**

$$\frac{13}{7}\left(p + \frac{17}{8}\right) = \frac{23}{5}p + \frac{241}{280}$$

## BLOQUE 5: Problemas de Mezclas y Concentraciones (Ejercicios 121 a 128)

### **Ejercicio 121**

- **Datos:** $x$ lb al $88\%$, $12$ lb de níquel puro ($100\%$) para dar mezcla al $96\%$.
- **Ecuación:**
  $$0.88x + 1.00(12) = 0.96(x + 12)$$
  $$0.88x + 12 = 0.96x + 11.52$$
  $$0.08x = 0.48 \implies x = 6\text{ libras}$$

**Respuesta:** Se deben combinar **$6\text{ libras}$**.

---

### **Ejercicio 122**

- **Datos:** $7$ cuartos al $c_1$, $5$ cuartos al $34\%$, resultando $12$ cuartos al $20\%$.
- **Ecuación:**
  $$7 c_1 + 5(0.34) = 12(0.20)$$
  $$7 c_1 + 1.70 = 2.40 \implies 7 c_1 = 0.70 \implies c_1 = 0.10 = 10\%$$

**Respuesta:** La concentración de la primera solución era del **$10\%$**.

### **Ejercicio 123**

- **Datos:** $2\text{ m}^3$ al $17\%$, $6\text{ m}^3$ a concentración $p$, total $8\text{ m}^3$ al $14\%$.

  $$2(0.17) + 6p = 8(0.14)$$
  $$0.34 + 6p = 1.12 \implies 6p = 0.78 \implies p = 0.13 = 13\%$$

**Respuesta:** El contenido de limo del segundo tipo era del **$13\%$**.
